# Approved web photographs

Upload the 30 WebP files from `enfjp-gallery-photos-to-upload.zip` into this directory on the `photography-selected-ten` branch. Do not upload the ZIP file itself, source PNG masters, screenshots, or the old CV.

These are the ten photographs selected by the author, in three sizes per photograph. Descriptive asset names are internal paths only; the gallery displays neither filenames nor numerical labels.

The branch-specific workflow builds and checks the pages after the images are uploaded. The main branch and live site are not changed until the prepared branch is merged.
