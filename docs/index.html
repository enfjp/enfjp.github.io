01

Watermarking through graph invariants

InvGNN-WM ties ownership verification to a graph neural network’s prediction of a topological invariant. We study task preservation, robustness to model edits, and the conditions under which exact watermark removal is computationally hard.

Is noise conditioning necessary?

We study when corrupted graph structures contain enough information to make explicit noise-level conditioning unnecessary, combining a theoretical analysis with experiments on graph diffusion models.
