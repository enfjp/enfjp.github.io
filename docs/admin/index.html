仅允许 enfjp 管理 enfjp.github.io。令牌只保留在当前页面内存中，退出或刷新后清除；不要把令牌发送到聊天、截图或仓库。

首次使用：怎样创建授权？

在 GitHub 创建 Fine-grained personal access token，Resource owner 选择 enfjp，Repository access 选择 Only select repositories，仅勾选 enfjp.github.io。Contents 选择 Read and write，其他权限不要增加。建议设置 30 天有效期。

添加新照片

选择 JPEG、PNG 或 WebP。浏览器生成长边最多 800、1400、2048 像素的三个版本，保持构图，不上传母版。每次最多 20 张；生成后先检查预览与文字，再保存发布。

管理页不自动判断照片好坏，也不保证识别人物。请确认准备公开的照片符合你的无人像选片要求，并保留原始成片。网页压缩为有损处理，文件大小不是固定 1.08 MB。

拍摄地点

同一地点可以同时用于 Wild、Land 和 On the road。只显示有已上架照片的二级地点入口，不重复存储照片。

下架只会撤下网站中的展示，不代表照片变为私密。删除会从当前图库和当前版本图片目录移除文件，但 GitHub 历史及缓存仍可能保留副本；不影响你硬盘或 Google Drive 中的原片。
