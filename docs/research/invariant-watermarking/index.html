Robust and Hard-to-Remove GNN Watermarking via Topological Invariant Perception

IN ONE QUESTION

Can a model watermark be tied to the graph structure a neural network learns, rather than an external backdoor trigger?

The question

Many graph neural network watermarks rely on out-of-distribution backdoor triggers that can weaken after model edits. We ask whether the ownership signal can instead be coupled to learned graph structure while preserving the primary task.

The approach

InvGNN-WM jointly trains the task model and a lightweight scalar head that predicts normalized algebraic connectivity on owner-private carrier graphs. A threshold decoder converts the predictions into watermark bits; a calibrated acceptance threshold is used for black-box ownership verification.

What we found

The experiments examine node and graph classification under pruning, fine-tuning, and post-training quantization. Plain knowledge distillation weakens the watermark; adding the watermark loss is an owner-side recovery procedure that requires the private carriers and key. The theoretical guarantees depend on the stated assumptions: output drift below the carrier margin preserves decoded bits, and the NP-completeness result concerns exact removal within a specified separable, coordinate-wise monotone decoder class.
